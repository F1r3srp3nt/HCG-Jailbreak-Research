# Architecture

```
HCGAnimationCenter/
  HCGBackgroundKit/        reusable component (Swift package): preset format, C rules, renderer
  src/                     SpringBoard tweak (HCGAnimationCenter.dylib) + shared preferences/policy
  preferences/             Settings bundle (HCGAnimationCenterPrefs.bundle)
  tests/ preview/ scripts/ docs/ distribution/
```

## Processes and data

```
 Settings.app (HCGAnimationCenterPrefs.bundle)                 SpringBoard (HCGAnimationCenter.dylib)
 ───────────────────────────────────────────                 ──────────────────────────────────────
 import (Photos / Files) → HACMediaImporter                      HACController (one per process)
   video track only / GIF → H.264, still, thumbnail                ├─ HACSurface Home ─ HCGBackgroundView
   → /var/mobile/Library/HCGAnimationCenter/Media/               └─ HACSurface Lock ─ HCGBackgroundView
 library.json (Settings only)                                    reads preferences, never library.json
 editor → preset (HCG format v1)                                 reads Media/ files named by the presets
 Apply → CFPreferences homePreset / lockPreset ── Darwin ───────▶ preferences-changed → reconcile
 Status rows ◀── CFPreferences …status ◀──────── status-updated ─ writeStatus
 Write Hierarchy Probe ─────────────── probe-request ──────────▶ Diagnostics/hierarchy-*.txt (read-only)
```

The assigned backgrounds are stored as **complete preset documents** in the preferences, so SpringBoard does not
depend on the library file; a damaged library cannot break the running background, and a deleted item clears its
assignments first.

## SpringBoard lifecycle (`src/HACController.m`)

1. `%ctor` → `HACControllerBootstrap`: only in `com.apple.springboard`; kill switch file → stop; launch guard (3 quick
   launches in a row while enabled → *Auto-disabled*); wait for `UIApplicationDidFinishLaunchingNotification` (8 s
   fallback).
2. `apply`: enabled → `activate` (observers, the one hook, attach each assigned surface); disabled or faulted →
   `deactivate` (remove both views, free decoders, stop observers).
3. Each surface finds a host with `HACFindHost` (`src/HACHosts.m`; ladder in `SPRINGBOARD_RESEARCH.md`), retrying 15 ×
   2 s, and inserts its `HCGBackgroundView` (index 0, or on top of a wallpaper view). If SpringBoard removes the host,
   it re-attaches.
4. Every input change calls `updateAll`: `hac_decide()` (`src/HACPolicy.c`) → `system | still | paused | playing` per
   surface → the view's `display`. Paused surfaces free their decoder after 8 s; memory warnings free every hidden one.
5. Any Objective-C exception → `fault`: views removed, state *Fault*, system wallpaper visible; Enable off/on retries.

Inputs: `com.apple.springboard.hasBlankedScreen`, `com.apple.springboard.lockstate` (notify state, read-only),
`-[SpringBoard frontDisplayDidChange:]` (the only hook), Reduce Motion, Low Power Mode, thermal state, memory warnings.

## The renderer (`HCGBackgroundKit/…/HCGBackgroundView.m`)

```
layer (background colour) └─ clip ├─ still layer (ImageIO thumbnail, ≤ screen size)
                                   └─ AVPlayerLayer (hidden until the first frame is ready)
```

- Video: `AVMutableComposition` with **only the video track** for the trim range → `AVQueuePlayer + AVPlayerLooper`
  (loop) or `AVPlayer` (once, holds last frame). Muted, no external playback, never prevents display sleep,
  `preferredMaximumResolution` = what the layout needs at screen scale, 1 s forward buffer.
- Layout from `hcgbg_layout` (C). Scaling, crop, colour and speed changes apply **in place** (no reload); file, trim,
  loop or still changes reload.
- Failures (missing file, unreadable asset, no video track, item / player / looper failure, failed-to-play-to-end) →
  decoder freed, `mediaFailed`, one delegate call, still remains.
- Never hit-tests, hidden from accessibility.

## Settings (`preferences/`)

| Class | Role |
|---|---|
| `HACRootListController` | main page (Root.plist generated by `scripts/generate_root_plist.py`); reads/writes CFPreferences; live status |
| `HACLibraryViewController` | grid, Photos/Files/preset import, progress + cancel, choose-for-surface mode |
| `HACEditorViewController` | preview stage (same renderer, screen aspect, icon / clock overlays), trim, scaling, crop (zoom + drag), loop, speed, still, Apply / Export / Delete; also the AI preview |
| `HACAIViewController`, `HACAIGeneration` | later-phase AI interface (`AI-BACKGROUNDS.md`) |
| `HACLibrary`, `HACMediaImporter` | store and import (`LIVE-BACKGROUNDS.md`) |

## Files on the device

| Path | Owner | Removed by |
|---|---|---|
| `/var/jb/Library/MobileSubstrate/DynamicLibraries/HCGAnimationCenter.{dylib,plist}` | package | uninstall |
| `/var/jb/Library/PreferenceBundles/HCGAnimationCenterPrefs.bundle`, PreferenceLoader entry | package | uninstall |
| `/var/mobile/Library/Preferences/com.hakmicapitalgroup.animationcenter{,.status}.plist` | Settings / SpringBoard | **purge** (postrm) |
| `/var/mobile/Library/HCGAnimationCenter/` (Media, library.json, Exports, Diagnostics, Staging) | Settings | **purge** (postrm) |
| `…/com.hakmicapitalgroup.animationcenter.disabled` | you (kill switch) | you, or purge |

The system wallpaper files and settings are never read for content or written.
