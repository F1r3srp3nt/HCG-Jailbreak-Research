# Compatibility-checking logic

Code: `academy/assets/compat.js` (`HCGCompat.evaluate`). Data: `academy/assets/compat-data.js`, generated by
`tools/build_compat_data.py` from AppleDB. Tests: `tests/compat.test.mjs`.

Two kinds of input, kept apart on purpose:

- **Hardware and release facts** (which chip a model has, which iOS versions Apple shipped for it) are generated from
  AppleDB and never edited by hand.
- **Dopamine's supported ranges** are hand-copied from the developer's README and website into `RANGES`, each with its
  source. Nothing is inferred.

## Inputs

| Question | Values |
|---|---|
| Exact model | one of 85 iPhone/iPad models that received iOS/iPadOS 15 or later (search by name, A-number, identifier or chip) |
| iOS/iPadOS version | free text, normalised (`17` → `17.0`, `iOS 16.7 (20H18)` → `16.7 RC`) |
| Build (only for 16.7) | 20H18 (RC) · 20H19 or other · not sure |
| Existing jailbreak | none · Dopamine · palera1n rootless · palera1n rootful · nathanlr/Relaxin/Serotonin/Bootstrap · another · not sure |
| TrollStore installed | yes · no · not sure |
| Backup | yes · no |
| Ever updated iOS | yes · no (factory version) · not sure |

## Decision order

1. No model chosen, or unknown → **cannot yet be verified**.
2. Version not parseable → **cannot yet be verified**.
3. Major version < 15 → **unsupported** (Dopamine starts at 15.0).
4. Version is 16.7 and no build given → **cannot yet be verified** (asks for the build: RC 20H18 can use TrollStore).
5. Version is not a shipped release (typo, beta, internal build) → **cannot yet be verified**.
6. Apple never shipped that version for that model → **cannot yet be verified** (one of the two answers is wrong).
7. Chip not in A8–A17 / M1–M2 → **unsupported**.
8. Version/chip not inside any range → **unsupported**:

   | Range | Chips | Source |
   |---|---|---|
   | 15.0 – 17.3.1 | A8–A17, M1–M2 | website, README |
   | 17.4 – 18.7.1 | A8–A13 | README (“arm64”, “A12/A13”), website (“A8 - A13”), cfw.guide (“A13 and earlier”) |
   | 26.0 – 26.0.1 | A8–A13 (only A12/A13 ever ran iOS 26) | README, website |

9. Route (ios.cfw.guide):
   - **TrollStore route** when TrollStore can run (TrollStore README: 15.0–16.6.1, 16.7 RC, 17.0). If TrollStore is not
     installed, the installer is chosen from the cfw.guide tabs:

     | Version | A8/A8X | A9–A11 | A12 and later |
     |---|---|---|---|
     | 15.0 – 15.4.1 | TrollHelperOTA | TrollHelperOTA | TrollHelperOTA |
     | 15.5 – 15.6.1 | TrollInstallerMDC | TrollInstallerX | TrollHelperOTA |
     | 15.7 – 15.7.1 | TrollInstallerMDC | TrollInstallerX | TrollInstallerX |
     | 15.7.2 – 15.8.6 | TrollRestore | TrollInstallerX | TrollInstallerX |
     | 15.8.7 – 15.8.8 | TrollRestore | TrollRestore | TrollRestore |
     | 16.0 – 16.6.1 | — | TrollInstallerX | TrollInstallerX (+ extra steps: A12+ on 16.6–16.6.1, A15/A16/M2 on 16.5.1) |
     | 16.7 RC, 17.0 | — | TrollRestore | TrollRestore |

     Requirements added: a computer (TrollRestore, TrollInstallerMDC; TrollInstallerX unless jailbreaks.app signs it),
     Find My off (TrollRestore), the extra persistence-helper step where it applies.
   - **Sideload route** otherwise. Always adds requirements: computer + Apple Account (unless jailbreaks.app signs
     Dopamine), re-sign every 7 days, Developer Mode on iOS 16+. If the device has never been updated (factory
     version) → **cannot yet be verified**, because cfw.guide says this route does not work there and TrollStore
     cannot run: no documented route fits.
10. Existing jailbreak: rootful palera1n or nathanlr/Relaxin/Serotonin/Bootstrap → removal requirement; rootless
    palera1n → note (intercompatible); Dopamine → note; another/not sure → requirement to identify and remove.
11. No backup → requirement (listed first).
12. Notes: A12/A13 on 16.6+ screen flicker; 2 GB RAM respring workaround on 15.8.7–15.8.8 and 16.7+.
13. Verdict: **supported** if no requirements, else **supported with specific requirements**.

## Independent cross-check

`tests/compat.test.mjs` evaluates **every model × every shipped release** in the dataset (5,149 pairs) and
compares “supported or requirements” with membership in AppleDB's own Dopamine compatibility list. Result:
**0 disagreements**. (The first run found one: 17.5.2, an Apple-internal build AppleDB lists but Apple never released;
the generator now excludes internal builds.)
