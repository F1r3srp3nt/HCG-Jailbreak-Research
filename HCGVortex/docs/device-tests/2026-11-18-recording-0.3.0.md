## Checked and found correct

- **Completed swipes:** the destination grid is exactly in place at 7.40 s (Orbital) and 15.8 s (Tornado).
- **Reversed and cancelled swipes:** page 1 is exactly restored at 2.50 s (Orbital) and 17.8–19.4 s (Tornado).
- **Labels and badges:** restored after every transition. The badges ("32 656", "1", "2", "925") move with their icons
  and come back intact.
- **Clipping:** none seen. Formations stay inside the screen, and the dock is unaffected.
- **Stretching:** none seen. No effect in the recording scales icons non-uniformly.
- **Depth ordering:** consistent within each page. The incoming page draws above the outgoing page, as expected for
  sibling list views.
- **Magnetic Grid:** a near-stock page slide; no prolonged motion was visible.

## Coexistence with HCG Halo

Halo's edge glow stays visible and stable through every transition. No artefact lines up with Halo's elements.
- **F1 is not explained by Halo.** The flash matches a frame-ordering gap in Vortex: icon views appear after Vortex's
  pass in the same frame. Vortex 0.3.1 fixes that directly.
- **Halo is not ruled out either.** Its source is not available to inspect. Repeating two swipes per effect with Halo
  turned off would separate the two.

## Response (0.3.1~beta1)

See `CHANGELOG.md` 0.3.1-beta1 and `docs/media/0.3.1-before-after-device-layout.png`.
- **F1:**
  - a first-frame guard holds an incoming pinned page invisible on its first frame;
  - an optional `SBIconListView -layoutSubviews` hook re-applies icon visuals in the same frame after SpringBoard's own
    layout (installed only if that class implements the method itself);
  - hidden icon views are transformed too.
- **F2:** Tornado uses 3 interleaved spiral strands per page, with the other page between them, so every height of the
  funnel has icons around it. Icons are smaller and shrink towards the tip, the funnel is raised clear of the dock,
  and there are fewer turns per strand. Presets are retuned.
- **F3:** Orbital uses shared ring slots with fixed capacity per ring and an interleaved lattice, so the two pages
  never land on the same spot. Icons are smaller, both pages rotate together, and the tilt is flatter.
- **F2 and F3:** labels are hidden while an icon is shrunk into a formation, and restored with the grid.
- **Regression tests on the recorded layout** (414 × 896 pt, a 10-icon and a 24-icon page) fail on the 0.3.0 geometry
  and pass on 0.3.1:
  - Tornado: width at every height, tip above the dock, no pile-up;
  - Orbital: shared rings, no crowding.
